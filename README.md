# 🎨 IM COMPOSER — Neural Image Foundry & Strategic Reasoning Studio

> **Профессиональная студия генерации, автономного агентного арт-дирекшена, кадрирования и цветокоррекции изображений с поддержкой сторонних ИИ-провайдеров по URL и API-ключам.**

---

## 🌟 Ключевые возможности

### 1. Встроенная студия кадрирования и цветокоррекции (Image Editing Suite)
- **Интерактивное кадрирование (Crop Overlay):**
  - Пресеты соотношений сторон: `Свободный`, `1:1 (Квадрат)`, `16:9 (Широкий)`, `9:16 (Stories/Reels)`, `4:3`, `3:4`.
  - Удобная перемещаемая рамка с сеткой третей (Rule of Thirds) прямо поверх сгенерированного арта.
- **Цветокоррекция и фильтры в реальном времени:**
  - Настройка яркости (Brightness), контраста (Contrast), насыщенности (Saturation), теплоты (Warmth/Hue), сепии (Sepia) и ч/б (Grayscale).
  - Быстрые арт-пресеты в 1 клик: *Оригинал, Vivid Studio, Золото, Киберпанк, Нуар, Холодная сталь*.
- **Трансформация кадра:**
  - Поворот на 90° по часовой стрелке, зеркальное отражение по горизонтали и по вертикали.
- **Двухэтапный воркфлоу:**
  - Автоматическое открытие оверлея редактирования сразу после генерации (можно довести изображение до идеала перед сохранением в историю проекта).
  - Возможность открыть и отредактировать любое ранее сохраненное изображение из галереи или в полноэкранном режиме.

---

### 2. Подключение любых ИИ-провайдеров по URL и ключу
Полное решение проблемы лимитов и квот Google! Теперь вы можете подключить любого поставщика моделей:
- **Добавление по URL и ключу:**
  - Поддержка **любого OpenAI-совместимого API** (Base URL + Bearer API Key + Model Name).
  - Быстрые пресеты в один клик:
    - **OpenRouter** (`https://openrouter.ai/api/v1`) — доступ к бесплатным моделям `deepseek/deepseek-r1:free`, `meta-llama/llama-3.3-70b-instruct:free`.
    - **DeepSeek API** (`https://api.deepseek.com/v1`).
    - **Groq Cloud** (`https://api.groq.com/openai/v1`) — сверхбыстрый вывод `llama-3.3-70b-versatile`.
    - **Ollama / LM Studio (100% Локально и бесплатно)** (`http://localhost:11434/v1` или `http://localhost:1234/v1`).
    - **Официальный OpenAI** (`https://api.openai.com/v1`).
- **Встроенный пинг (Ping & Connection Test):**
  - Проверка доступности URL и валидности ключа с замером пинга (латентности в мс).
- **Отказоустойчивость:**
  - Если кастомный провайдер недоступен, система бесшовно обращается к локальному эвристическому движку Gemma Heuristics без выброса фатальных ошибок.
- **Резервный генератор картинок с нулевой квотой:**
  - При исчерпании квоты Google (`429 / RESOURCE_EXHAUSTED`), система автоматически активирует резервный движок высокой четкости Flux/Pollinations, сохраняя бесперебойную работу.

### 3. Режимы работы и когнитивные агенты
- 🕹️ **Manual (Базовый):** Прямой синтез матриц изображений с композицией референсных ассетов, согласованием света и теней.
- 🎬 **Agent (Арт-директор):** Автономный агент составляет 4-шаговый производственный пайплайн, проводит художественное исследование трендов и выполняет финальный рендеринг.
- 🏛️ **Consilium (Консилиум 3 экспертов):** Архитектор (перспектива/композиция), Стилист (колористика/детали) и Гармонизатор (свет/текстуры) выдают детальную критику и улучшенный промт.
- ⚡ **Symposium (Дебаты мыслителей):** Диалектический спор Мастера (практика/реализм), Ментора (философия/гармония) и Ученика (инновации/бунт), завершающийся 3 альтернативными мастер-промтами.
- 🎙️ **Live Voice Hub:** Голосовой брейншторм в реальном времени через распознавание речи (Web Speech API) и синтез голоса (Gemini TTS / Browser Speech).

## 📐 Архитектура КЭМ (qem Core) и градиент гармонии (∇ε_Total)

Проект спроектирован по критерию **∇ε_Total = w_C · C + w_D · D + w_B · ∇ε_B**:
- **C (Consequentialism — Последствия):**
  - Пользователь больше не блокируется квотами благодаря поддержке бесплатных моделей OpenRouter и локальной Ollama.
  - Кадрирование и фильтры на стороне клиента не расходуют сетевой трафик и серверные ресурсы.
  - Безопасное хранилище `safeSetStorage` защищает от переполнения квоты памяти `localStorage` (5 МБ) при сохранении base64 изображений.
- **D (Deontology — Принципы и приватность):**
  - Все API-ключи хранятся **исключительно локально** в браузере клиента (`localStorage`), никогда не передаются на внешние сторонние серверы телеметрии.
  - Прозрачные индикаторы статуса, ручное тестирование соединений.
- **∇ε_B (Системная гармония и чистота кода):**
  - Единый контракт OpenAI-совместимых запросов `callOpenAICompatibleChat` для всех провайдеров.
  - Четкое разделение слоев: визуальные модальные окна (`ImageEditorModal`, `CustomProvidersDialog`), сервисный слой (`providersService`, `geminiService`), типы (`types.ts`).

## 🚀 Быстрый старт

### Требования
- Node.js >= 18.0.0
- npm, pnpm или yarn

### Установка зависимостей
```bash
npm install
```

### Настройка окружения
Скопируйте шаблон переменных окружения:
```bash
cp .env.example .env
```
*(Все ключи также можно настроить и сохранить прямо в интерфейсе приложения в диалоге «ИИ Провайдеры»).*

### Запуск в режиме разработки
```bash
npm run dev
```
Приложение откроется на порту `http://localhost:3000`.

### Сборка для продакшена
```bash
npm run build
```

Проверка готовой сборки:
```bash
npm run preview
```
